## Changes

- **Course load fallback**: When a course has no lessons/tasks/assessments, the auto-created task is now fully loaded into the builder via `loadTaskIntoBuilder` and `selectedItem` is set, so the builder never stays in an empty state.
- **Kebab Deploy item**: Removed `focus-visible:bg-white/10` flash and brightened the text to `emerald-300`.
- **Move to Lesson dialog**: Restyled with the metallic dark panel theme, white text, removed the unreadable `Destination lesson` label, and replaced the native `<select>` with the app `<Select>` component.
- **Record Demo panel**: Unified tab content height at 360px (~15% smaller), added sliding-pill tab animation matching the Course Selector, and reduced the recorder preview max-height to 270px.
